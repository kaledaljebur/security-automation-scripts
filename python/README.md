## Instructions

1. Open the Terminal
    - Open a terminal window in Kali Linux.

2. Navigate to the Desktop
    - `cd ~/Desktop`
3. Clone the Repository
    - Download the repository from GitHub:
    - `git clone https://github.com/kaledaljebur/security-automation-scripts.git`
    - This will create a new folder named: `security-automation-scripts`
4. Enter the Repository Folder
    - `cd security-automation-scripts/python`
5. Run a Script
    - To run a script from the current python folder, use:
    - `sudo python 1.py`
    - Replace `1.py` with the script required for the activity.
    - Example: `sudo python 10.sh`

### Notes
- sudo is required because some scripts perform security checks that need administrator privileges.
- Always read the script before running it to understand what it does.
- These scripts are designed for learning basic security automation using Python.
