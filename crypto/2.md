This lesson is an introductory practical activity on password hash cracking techniques. The purpose is to help you observe the difference between brute-force attacks, dictionary attacks, rainbow table attacks, and online password guessing using simple examples in Kali Linux. You should run the commands, observe the output, and discuss the meaning of the results during the lesson.

## Brute Force

This activity introduces brute-force cracking. You will see how a tool can try many possible values automatically until it finds the correct one. This helps explain why short and simple passwords are weak.

[Hashcat Source](https://www.kali.org/tools/hashcat/)
```bash
# Move to Desktop if preferred
cd ~/Desktop

# Create sample sha256 and save in hashes.txt
echo -n '123' | openssl dgst -sha256 | awk '{print $2}' | tee hashes.txt

# Read
cat hashes.txt

# Crack the hash in hashes.txt file
hashcat -m 1400 -a 3 hashes.txt ?d?d?d
# -m 1400 -> is sha256
# -a 3 -> brute-force / mask
    # -a 0 -> dictionary attack
    # -a 1 -> combinator attack
    # -a 3 -> mask/brute-force attack
    # -a 6 -> dictionary + mask
    # -a 7 -> mask + dictionary
# ?d -> digit
# three ?d = try all 3-digit numbers
```

## Dictionary Attack

This activity introduces dictionary attacks. Instead of trying every possible combination, the attacker tests words and passwords from a prepared list. This helps you understand why common passwords are easy to guess.

```bash
# In the terminal, type the command below and answer yes to the question
# Or you can use any other dictionary file
wordlist

# Check whether the actual string is available in the dictionary
grep -x '123' rockyou.txt

# Back to the Desktop
cd ~/Desktop

# Crack
hashcat -m 1400 -a 0 hashes.txt /usr/share/wordlists/rockyou.txt --show
```

## Rainbow Table

This activity introduces rainbow tables. A rainbow table is a table prepared before the attack that contains many possible password values and their related hashes. You will see how these tables can be used to search for matching hashes more quickly. This helps explain why stored passwords should be protected properly and why weak password choices are risky.

[Rainbowcrack Source](https://www.kali.org/tools/rainbowcrack/)
```bash
# Install Rainbow if not available already in Kali
sudo apt update && sudo apt install rainbowcrack

# Generate the rainbow table
# The table will be /usr/share/rainbowcrack/sha256_numeric#3-3_0_1000x1000_0.rt
# hence the need for sudo
sudo rtgen sha256 numeric 3 3 0 1000 1000 0
# sha256 -> The hashing algorithm you are targeting
# numeric -> The character set (uses only numbers 0-9)
# 3 3 -> The minimum and maximum password length (exactly 3 characters here)
# 0 -> The Table Index (used to create unique reduction functions)
# 1000 -> The Chain Length (how many passwords are "linked" in one row)
# 1000 -> The Chain Count (how many rows the table will have)
# 0 -> The Part Index (used if you were splitting a massive table into multiple files)

# rtsort needs to sort the table generated by rtgen, otherwise rcrack will search the whole table
sudo rtsort .

# This will search and compare with the hashes in the rainbow table
sudo rcrack . -l /home/kaled/Desktop/hashes.txt
# You may use rcrack . -h <insert_hash_here>
```

## Hydra Activity

This activity has been tested in Kali Linux.

This activity introduces Hydra as an online password guessing tool. You will test a weak SSH password against a local account and observe how quickly a weak password can be found when a login service is running.

[Reference source](https://www.kali.org/tools/hydra/)

```bash
# Create a test account with a weak password such as abc123

# Or use the command below to change the password of an existing test account to a weak one
sudo passwd kali

# Start the SSH service in Kali Linux
sudo systemctl start ssh

# Check whether the weak password exists in the dictionary file
head /usr/share/wordlists/rockyou.txt
123456
12345
123456789
password

# Use Hydra to crack the password
hydra -l kali -P /usr/share/wordlists/rockyou.txt -t 4 ssh://127.0.0.1
```

## John the Ripper Activity

This activity introduces John the Ripper as another password cracking tool. You will combine the account information from `/etc/passwd` and `/etc/shadow`, then use John the Ripper to test password cracking against the resulting file.

[Reference source](https://www.kali.org/tools/john/)

```bash
# Move to the Desktop if preferred
cd ~/Desktop

# Combine passwd and shadow information into one file
sudo unshadow /etc/passwd /etc/shadow > mypasswd

# Read the generated file
cat mypasswd

# Try cracking the hashes using the default mode
john --format=crypt mypasswd

# Try cracking the hashes using the rockyou wordlist
john --format=crypt --wordlist=/usr/share/wordlists/rockyou.txt mypasswd

# Show cracked results
john --show mypasswd
```
